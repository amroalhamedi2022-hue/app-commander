# App Commander

تطبيق أندرويد شخصي يجمع **Activity Launcher** و**App Manager** وطبقة تحكم متقدمة عبر **Shizuku** مع تصميم سائل ومتدرّج. يعمل محليًا ولا يطلب إذن الإنترنت.

## الموجود في النسخة 0.1.1

- عرض كل التطبيقات مع البحث والفرز إلى تطبيقات المستخدم والنظام والمعطّلة.
- Usage Access لعرض استخدام آخر 24 ساعة.
- صفحة تفاصيل لكل تطبيق: الإصدار وTarget SDK وActivities وServices وReceivers والأذونات.
- تشغيل الـActivities المصدّرة مباشرة.
- فتح إعدادات التطبيق والأذونات والبطارية، وتشغيل التطبيق أو طلب إزالته.
- فحص ملف APK محليًا: الحزمة، الإصدار، SDK، المكوّنات، الأذونات، SHA-256 وبصمات الموقّعين.
- تثبيت APK المختار عبر مثبّت أندرويد.
- أربع لوحات ألوان سائلة: محيطي، بنفسجي، نعناعي، وغروب.
- دعم واجهة الهاتف والتابلت وRTL.

## التحكم المتقدم

عند تشغيل Shizuku ومنح App Commander الإذن، تظهر أوامر:

- Force stop.
- تجميد التطبيق وإلغاء تجميده.
- منع العمل في الخلفية أو السماح به عبر AppOps.
- منح وسحب Runtime permissions عندما يسمح النظام.
- تفعيل وتعطيل Activities وServices وReceivers، ومنها مستقبلات بدء التشغيل.

وضع Device Owner مهيأ أيضًا لتعليق التطبيقات وإخفائها. يحتاج إعدادًا خاصًا من ADB على جهاز مناسب، لذلك Shizuku هو المسار العملي المفضّل للاستخدام اليومي.

## البناء

المتطلبات: JDK 17، Android SDK 36، وGradle 9.6. افتح المجلد في Android Studio أو شغّل:

```bash
./gradlew :app:assembleDebug
```

الملف الناتج يكون في `app/build/outputs/apk/debug/app-debug.apk`.

تم بناء النسخة `0.1.1-safe-debug` بنجاح عبر GitHub Actions. حد أندرويد الأدنى هو API 28 والهدف API 36.

### حماية النظام

الإصدار 0.1.1 يحافظ على جميع وظائف التحكم لتطبيقات المستخدم وتطبيقات النظام غير الحساسة. الأوامر المؤذية فقط تُمنع عن مكونات النظام الحرجة مثل System UI واللانشر والإعدادات ومدير الأذونات ولوحة المفاتيح الافتراضية. أوامر الإصلاح العكسية مثل التفعيل وإلغاء التعليق تظل متاحة. محرك Shizuku يقبل عمليات محددة ومدققة بدل تنفيذ نص Shell عام.

## المرحلة التالية

- حفظ Profiles وقوائم تجميد مخصصة.
- تنفيذ قواعد الأتمتة عند إطفاء الشاشة وفتح تطبيق أو مغادرته.
- إضافة تحليل AppOps أوسع واستهلاك البيانات والتخزين.
- Backup/restore لإعدادات التطبيقات وقوائم المكوّنات.
